Alternância de vista sobre o mesmo dado — recorte temporal, unidade, submercado.

```jsx
<Tabs items={['horário','semanal','mensal']} familia="intelligence" />
<Tabs items={[{value:'ger',label:'Geração'},{value:'car',label:'Carga'}]} value={v} onChange={setV} />
```

Ativa é peso 500 com fio de 2px sob o texto, na cor da família. **Nunca fundo preenchido, nunca pílula.** Sem `familia`, o fio usa `--accent-house`.
