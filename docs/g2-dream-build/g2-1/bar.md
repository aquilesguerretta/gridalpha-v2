# NIVAR G2.1 — external craft bar

Experimental bar, 11 September 2026. This replaces the earlier structural-pass bar for G2.1 comparison; it does not revise product truth, approve a design, or permit changes to Alexandria. Authority: [owner brief §§5–6, 9–22, 27–29, 34–39](../g2-1-owner-brief.md). Evidence and live/archive distinctions: [reference dossier](../g2-1-reference-dossier.md).

**Pass means that a current NIVAR render competes with the relevant external render in a direct comparison, with no major craft gap left unaddressed.** Build success, screenshots existing, consistency, time spent and a previous weak bar do not establish a pass. A failed comparison returns one largest visible gap, then one correction and a new render.

## Critic protocol

| Critic | Receives | Must return |
| --- | --- | --- |
| Brief | User purpose/constraints and current artifact; no builder defense. | PASS/FAIL for achieved purpose, truthful product/evidence behavior and required deliverables. Name the one largest unresolved gap. |
| System | Current experimental system and current renders; no work history or effort report. | PASS/FAIL for intentional cross-surface roles, typography/material/color consistency and protected boundaries. |
| Craft | Actual external reference renders and equivalent NIVAR renders, neutral A/B framing where possible; actual playback/frame sequence for temporal questions. No implementation, tests, feature list, rationale or “we already fixed” narrative. | Which is stronger in composition, typography, depth, materiality, intention, memory, studio-portfolio quality and motion/life? If NIVAR loses, **one biggest gap** and PASS/FAIL. Mark motion unassessed if only stills are available. |

Use fresh contexts and the strongest available visual-capable model for the craft comparison, as required by the brief. A separate agent with inherited build context is implementation-aware, not fresh. One later passing functional check cannot reverse an earlier craft failure. After a correction, capture again and obtain the applicable new verdict.
