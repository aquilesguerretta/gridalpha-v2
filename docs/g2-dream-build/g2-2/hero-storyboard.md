# Hero G2.2 — native choreography, iteration 07

The G2.1 films were replayed in real time to `ended` at 26.125s and 26.5s. See baseline/playback.json and sampled playback sheets. The panel is already complete at frame one; the datum disappears when the table becomes a plot. That is the rejected baseline, preserved in git and the reference pack.

## Mechanisms borrowed, expression not copied

- Media.Work, live opening inspected 2026-09-11: frame-filling subject and controlled negative space. Translate to identified Itaipu photography, not product packshots or invented laboratory objects.
- CRED / Must: persistent object survives spatial reorganization. Translate to the same keyed sample and bracket becoming record, row, chart observation and publication evidence.
- Harvee is a dot-matrix/donut reference, not a line-series algorithm. Only the general context-driven shape change was useful. The NIVAR series uses its own native coordinates; values never count through invented readings and gaps never become connecting lines.
- Podium: final act earns its scale. Diógenes is the open investigation, not a thumbnail or a definitive verdict.

## 18 seconds, six three-second movements

1. **Medir** — real aerial geography, then real transmission. Image credits remain attached to the image. A deliberately separate synthetic study begins: 68, then MW, then 00:00. No connector claims that the synthetic reading was measured at Itaipu.
2. **Organizar** — the same bracketed 68 moves into the first row. Five time positions gain values or declared absence. Ariadne accompanies the alignment. Time and unit appear before the table rules.
3. **Observar** — the six existing objects move into temporal positions. An axis becomes necessary; only the consecutive 68–64 samples join. Null intervals stay open. Argos focuses the 68 and 108 endpoints while interior observations recede.
4. **Questionar** — the same geometry admits a competing reading. Two missing intervals are revealed. A 68→108 comparison cannot establish an uninterrupted trend.
5. **Transmitir** — the existing plot and its source become a mineral publication, with the limitation carried alongside. No change of evidence identity.
6. **Procurar** — the publication stays open; the first datum remains visible. Diógenes re-emphasizes the two missing observations and asks what remains to be observed to change the reading. The question holds beside NIVAR and the voluntary House action. The published evidence exits as one plane and the real landscape returns for a natural 18-second cycle. Manual chapter selection pauses for reading.

Phone composition uses its own coordinates and text scale. The exact data are the original didactic `[68,64,null,81,null,108]` MW over an illustrative day. Photographs are never presented as their source.

## Implementation constraints

Native SVG and HTML on one bounded requestAnimationFrame clock. No additional motion library. Offscreen and hidden-tab pause, explicit transport, chapter access, reduced-motion still, no essential information available only through playback. Responsive WebP real photographs; original bytes and licenses retained separately. No API/business/security changes.

## Rejected before implementation

- Orange atmospheric connector: endpoints lacked exact semantics.
- Real pylon → 68 MW: factually false measurement implication.
- Reusing a full glass panel as every scene: reproduces G2.1's main failure.
- Procedural ThreeUI particle networks: library renderers do not encode this domain's relationships.

## Failure history and correction

Iteration 02 was rejected by the independent craft critic: a small graph beside repeated portraits, crowded diagonal row travel, doubled captions, ambiguous translucent paper. Iteration 03 enlarged the evidence field and separated horizontal/vertical motion. Iteration 04 makes the paper opaque, colors each persistent observation as the physical edge crosses behind it, retires the portrait behind the sheet and corrects mobile chart padding. Outgoing copy clears before the new statement arrives.

The original G0/G1 constitution §5.19 asks for approximately 15–18 seconds and a natural loop. The G2.2 reference sheet's suggested House handoff was not an override of that written requirement. The native clock therefore uses 18 seconds; the House link remains a voluntary handoff. Earlier 36-second one-shot captures remain preserved as rejected evidence. The delivered motion is not a time-stretched movie: the interface itself runs on the native 18-second clock.

## Final material correction

Iteration 05 preserved a coherent exit, but a fresh critic still saw a cream rectangle sliding beneath independent chart anchors. Iteration 06 uses one evidence plane: it turns edge-on, changes to its opaque publication face while edge-on, and resolves with the same keyed observations and geometry. The patron leaves before the turn. The publication, chart and open question then depart together before the opening words return. This is native CSS perspective on semantic HTML/SVG, not an additional runtime library or rendered fake telemetry.

Iteration 07 adds explicit endpoint focus and reopens the absent slots. The independent critic accepted all seven craft criteria after whole desktop and phone playback; see `critics/craft-hero-03/iteration07/amendment-review.md`. Earlier rejected films and reports remain available.
