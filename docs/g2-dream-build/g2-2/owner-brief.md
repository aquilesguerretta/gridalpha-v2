# ====================================================================

The current orange line is not automatically good merely because it looks
technical.

The owner specifically identified instances where the line:

- terminates vaguely
- does not clearly connect source and result

NEW RULE:

NO CONNECTOR LINE WITHOUT SEMANTIC CAUSALITY.

Every line must answer:

FROM WHAT?

TO WHAT?

WHY?

remove the line.

- a physical object
- a point in the landscape
- a measurement
- a map region
- a document line
- a selected chart point
- a source record

It may terminate in:

- a data field
- a chart point
- a provenance record
- a structured value
- a question
- another meaningful object

Never use a line as decoration.
