# Codex live-reference capture plan

The pack intentionally does not redistribute screenshots from commercial design sites. Codex should open these references live and capture its own temporary review screenshots inside `docs/`.

For every capture, record URL, viewport, date, and mechanism. Do not ship these screenshots as NIVAR production assets.
