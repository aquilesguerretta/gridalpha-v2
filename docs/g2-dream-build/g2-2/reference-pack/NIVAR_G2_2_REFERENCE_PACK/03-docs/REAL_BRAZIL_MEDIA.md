# Real Brazil media and factual visual sources

Goal: give NIVAR real Brazilian visual truth wherever real material is available.

This file distinguishes:

- **production candidate**: license is explicitly open enough to consider using, with the stated obligations
- **reference / permission check**: visually valuable, but verify terms or obtain permission before shipping
- **data / geography source**: factual source for maps, layers, provenance, and geometry

Do not infer permission from appearance on the public web.

Contains explicit historical/field subjects including:

- Furnas construction

- transmission maintenance
- Mascarenhas de Moraes plant
- engineers/workers in the field
- early hydroelectric construction

Status:
REFERENCE / PERMISSION CHECK unless specific reuse rights are confirmed.

Why this is useful:
It shows Brazil energy as labor, engineering, time, and territory rather than a generic clean-energy brochure.

# Recommended media strategy for the next hero

Instead of six generated generic scenes:

1. **Physical territory**
   Real Itaipu/transmission shot.
2. **Measurement / operational reality**
   Real control room or real equipment/field image.
3. **Geography**
   EPE source-backed system layer or licensed map geometry.
4. **Evidence transformation**
   Native NIVAR graphics/UI over real source material.
5. **Question/contradiction**
   Native UI, document, source, and analytical motion.
6. **Knowledge / house**
   Brand-generated visual system can take over once the real-world origin has been established.

This produces a clear hierarchy:

**Reality is real. Interpretation is NIVAR.**

Generated media can still be used for controlled connective tissue, transitions, abstract brand matter, or shots that cannot be sourced responsibly.
