# Codex / Astra start here

This pack is a research and craft bar for the next NIVAR pass. It is not a replacement for G0 or G1, and it is not a pre-approved redesign.

The goal is to attack the remaining weak points in G2.1 without losing the structural work that already succeeded.

Read in this order:

1. `NIVAR_G2_2_REFERENCE_SHEET.md`
2. `03-docs/CURRENT_GAPS.md`

Use the current G2.1 screenshots as problem targets, not as references to preserve.

Use the external captures as visual evidence only. They are reference material and are not licensed NIVAR runtime assets by virtue of being included here.

Use real Brazilian media only when the individual license or permission supports the intended use. Preserve attribution and license obligations.

The priority is not to make NIVAR resemble any one reference. The priority is to reach the same level of intention, motion, materiality, and craft while expressing NIVAR's own logic:

`reality -> evidence -> context -> contradiction -> understanding`

Highest-priority targets:

- rebuild the hero as one causal cinematic system
- make Software/Ariadne reveal relationships before revealing the Terminal
- replace tiny utility glyphs as emotional family identity with meaningful patron presence
- make Diógenes synthesize the entire house at the close
- add real Brazilian geographic and infrastructure truth
- increase Terminal motion and desirability without implying fake live data

Do not touch Alexandria.
