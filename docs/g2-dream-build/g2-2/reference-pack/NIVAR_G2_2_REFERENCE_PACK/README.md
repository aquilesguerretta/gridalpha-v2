# NIVAR G2.2 Reference Pack

Purpose: give Codex/Astra a sharper external design bar for the next NIVAR craft pass, with direct references, current-problem screenshots, real-Brazil source material, motion patterns, and implementation mechanisms.

This pack does **not** approve a new design and does **not** ask Codex to clone any external brand. The rule is:

> Copy mechanisms, not copyrighted expression. Reuse code/assets only where the license explicitly permits it.

Start with:

1. `NIVAR_G2_2_REFERENCE_SHEET.md`
2. `02-current-gaps/`
3. `03-docs/CAPTURE_PLAN.md`
4. `03-docs/REAL_BRAZIL_MEDIA.md`
5. `03-docs/IMPLEMENTATION_TOOLKIT.md`

The weak points this pack targets are:

- hero film is conceptually strong but not cinematic enough
- connector lines sometimes become decoration rather than evidence
- UI panels appear fully formed instead of being constructed causally
- Software/Ariadne exposes the Terminal too literally
- micro SVG family marks are useful as utility glyphs but weak as emotional identity
- Diógenes closing does not yet synthesize the house
- Terminal still has room for desire, motion, and optical depth
- family pages need different behavioral grammars, not only different assets
- real Brazilian territory, infrastructure, control rooms, and geography should carry more of the visual truth
