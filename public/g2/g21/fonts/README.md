# NIVAR G2.1 selected typography

These are unmodified WOFF2 files obtained from the official Google Fonts CSS API on 11 September 2026. Local delivery is scoped through aliases declared in `src/components/g2/g21-fonts.css`.

- **Nivar Literata** → Literata, normal and italic, weights400–600, optical sizing; Latin and Latin Extended subsets.
- **Nivar Manrope** → Manrope, normal, weights400–700; Latin and Latin Extended subsets. No native italic is supplied.
- **Nivar Geist Mono** → Geist Mono, normal, weights400–600; Latin and Latin Extended subsets.

Each family retains its original SIL Open Font License file in this directory. Exact binary source URLs, CSS requests and byte counts are recorded in `docs/g2-dream-build/g2-1/brand/font-provenance.json`. Other comparison families remain documentation-only.

The CSS aliases avoid altering unrelated surfaces. No Alexandria styles or fonts are changed by these files.
